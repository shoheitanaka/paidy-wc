## 指摘
### [R1-1][Medium][.claude/skills/sync-from-jp4wc/SKILL.md 手順 2・5、check-setting-keys.php ヘッダー]
「プロパティ読み（`$gateway->testmode`）は PHPStan が `property.notFound` で拾う」という役割分担が、書かれた手順では働かない。
手順 5 は `composer phpstan:baseline && composer phpstan` の順なので、新しい `property.notFound` は baseline に吸収され exit 0 で通る（実測）。
また PHPStan が報告するのは型が分かる本体コードだけで、`tests/` は解析対象外、`array` / mixed 経由の読みも報告されない。
**修正方針:** 手順 5 に「再生成で baseline に増えた行（`git diff -U0 phpstan-baseline.neon` の `+` 行）が無いこと」を足し、PHPStan が拾う範囲を明記する。
