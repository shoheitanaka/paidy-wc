## 指摘（R1 の修正で新たに混入したもの）
### [R2-1][Low][.claude/skills/sync-from-jp4wc/SKILL.md 手順 5]
`grep '^+.*message:'` は新しいエントリだけを拾い、既存エントリの `count:` の増加（同じファイルに同じメッセージのエラーがもう 1 件）は 0 行のまま通る
（scratch のコピーで `WC()->payment_gateways->…` を 1 か所足して再生成: `-count: 1` / `+count: 2` だけで grep は 0 行）。
「件数が増えたら（上の `git diff` に行が出たら）」の括弧書きも、件数の増加と diff の行を同じものとして書いていて不正確。
Low の理由: 同じファイルに同じメッセージが既にある場合だけで、`phpstan:baseline` が出す総件数と「件数が減ること」の確認で気づける。
**修正:** grep をやめ、baseline を作り直す**前に** `composer phpstan` を実行して通常のエラーが 0 件であることを見る手順にした（本ラウンドで修正。B-25 は削除）
